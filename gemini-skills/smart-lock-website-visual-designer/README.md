# Gemini Skill: Smart Lock Website Visual Designer

This folder contains a reusable Gemini Skill for visual design work on the smart-lock ecommerce website.

## Files
- `SKILL.md`: Skill instructions and workflow.
- `project-brief-template.md`: Project source-of-truth template.

## Use
1. Download this folder or the repository ZIP.
2. Keep `SKILL.md` at the root of the folder named `smart-lock-website-visual-designer`.
3. Fill in the project brief with confirmed brand, market, product, and visual decisions.
4. In Gemini, open Skills and use Create / Upload to import the folder or a ZIP containing it.
5. Give the Skill the latest approved project brief and visual references.

Do not treat placeholders as product facts. Verify all technical claims, certifications, compatibility, warranty, and customer proof before publishing.
